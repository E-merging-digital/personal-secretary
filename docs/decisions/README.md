# Registre des décisions

Les décisions acceptées sont la source durable de vérité produit et architecture
du dépôt. Une issue GitHub porte le contexte et l'arbitrage ; une fois acceptée,
la décision correspondante est matérialisée ici.

## Règles

- Une décision acceptée prévaut sur une issue d'implémentation ordinaire.
- Une modification substantielle d'une décision passe par une nouvelle autorité
  GitHub et une PR de trust root.
- Les documents décrivent l'état durable attendu, pas l'historique complet des
  conversations.
- Les états live de PR, HEAD, CI et merge ne sont pas stockés ici.
